# 🚀 Simple DEX (Soroban on Stellar)

## 📌 Project Description
Simple DEX is a decentralized exchange smart contract built using Soroban on the Stellar network. It allows users to deposit tokens, withdraw them, and perform simple token swaps using predefined rates.

---

## ⚙️ What it does
- Allows users to deposit tokens into the contract
- Enables withdrawals of stored tokens
- Supports token swapping between two assets
- Maintains balances securely on-chain

---

## ✨ Features
- 🔐 Secure authentication using Stellar addresses
- 💰 Token deposit and withdrawal system
- 🔄 Basic token swap functionality
- 📊 On-chain balance tracking
- ⚡ Lightweight and gas-efficient design
